Menghitung Metrik Bisnis Utama (AOV & GMV)

Gunakan kueri SQL berikut untuk menghitung Gross Merchandise Value (GMV), Total Pesanan Sukses, dan Average Order Value (AOV) per bulan, lengkap dengan selisih pertumbuhan MoM (Month-over-Month) menggunakan window functions.

monthly_metrics.sql 
WITH monthly_summary AS (
  SELECT
    DATE_TRUNC('month', order_timestamp) AS txn_month,
    COUNT(order_id) AS total_orders,
    SUM(gross_amount) AS gmv,
    ROUND(AVG(gross_amount), 2) AS aov
  FROM fact_orders
  WHERE status = 'COMPLETED'
  GROUP BY 1
)
SELECT
  TO_CHAR(txn_month, 'YYYY-MM') AS bulan,
  total_orders,
  gmv,
  aov,
  ROUND((gmv - LAG(gmv) OVER (ORDER BY txn_month)) / 
        NULLIF(LAG(gmv) OVER (ORDER BY txn_month), 0) * 100, 2) AS gmv_growth_pct
FROM monthly_summary
ORDER BY txn_month;

psychology Interpretasi Bisnis & Temuan Analitis

Berdasarkan eksekusi kueri di atas pada dataset, terlihat lonjakan signifikan pada nilai Average Order Value (AOV) sebesar +24.6% pada periode Q4 (November - Desember). Namun, jumlah pesanan absolut (total_orders) justru mengalami penurunan 4.2%.

Penyebab Kenaikan AOV Konsumen memanfaatkan bundling musiman (Holiday bundle) untuk barang bernilai tinggi (elektronik & fesyen premium), bukan karena peningkatan volume pembeli baru.
Peringatan Red-Flag Churn Penurunan order volume diiringi anomali AOV adalah sinyal bahwa basis pelanggan bertransaksi lebih jarang, rentan bergeser ke kompetitor saat promo habis.

3 Tantangan Praktik
Tantangan 1: Analisis Frekuensi Pembeli (RFM - Frequency)

Kueri Pengguna dengan Transaksi > 3 Kali dalam 30 Hari

Tulis kueri SQL untuk memfilter seluruh user_id yang memiliki setidaknya 3 pesanan berstatus 'COMPLETED' dalam dataset. 

SELECT user_id, COUNT(order_id) AS order_count
FROM fact_orders
WHERE status = 'COMPLETED'
GROUP BY user_id
HAVING COUNT(order_id) >= 3;
Tantangan 2: Deteksi Kategori Produk Paling Rentan Batal

Hitung Rasio Pembatalan (Cancellation Rate) per Kategori

Lakukan JOIN antara fact_orders dan dim_products untuk menemukan kategori dengan rasio pembatalan pesanan di atas 15%. 

SELECT 
  p.category_name,
  COUNT(o.order_id) AS total_orders,
  ROUND(AVG(CASE WHEN o.status = 'CANCELLED' THEN 1.0 ELSE 0.0 END) * 100, 2) AS cancel_pct
FROM fact_orders o
JOIN dim_products p ON o.product_id = p.product_id
GROUP BY 1
HAVING AVG(CASE WHEN o.status = 'CANCELLED' THEN 1.0 ELSE 0.0 END) > 0.15;
Tantangan 3: Heatmap Matriks Retensi Bulanan di Seaborn

Buat Tabel Kohort Triangular

Gunakan method df.pivot_table() di pandas untuk menghasilkan matriks persentase retensi pengguna bulan ke-0 hingga bulan ke-6. 

cohort_matrix = df.pivot_table(index='cohort_month', columns='cohort_index', values='user_id', aggfunc='nunique')
retention_matrix = cohort_matrix.divide(cohort_matrix.iloc[:, 0], axis=0) * 100
sns.heatmap(retention_matrix, annot=True, fmt='.1f', cmap='YlGnBu')
