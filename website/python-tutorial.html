01. Pengenalan Python & Setup

Mengapa Python untuk DA, instalasi, Jupyter Notebook, pip, virtual environment

Python dipilih bukan karena tren, tetapi karena ekosistem datanya paling lengkap dan paling sering diminta di lowongan Data Analyst. Modul ini menyiapkan lingkungan kerja Anda: dari instalasi hingga notebook siap dipakai.

school Poin Kunci

  • Mesin: pasang Anaconda (praktis, sudah membawa Jupyter + library) atau Python dari python.org lalu tambah paket via pip.
  • Notebook: gunakan Jupyter Notebook untuk eksplorasi cepat dan JupyterLab untuk proyek berisi banyak file.
  • Isolasi: buat virtual environment per proyek agar versi library tidak saling bentrok.
# Siapkan lingkungan & dependency utama
python -m venv .venv
pip install pandas numpy matplotlib seaborn
jupyter lab

02. Variabel, Tipe Data & Operator

int, float, str, bool, casting, operator aritmatika/logika, f-string

Sebelum mengolah tabel, Anda harus nyaman dengan bahan dasar: angka, teks, dan nilai benar/salah. Kesalahan tipe data adalah penyebab paling umum error saat membaca CSV.

tag Poin Kunci

  • Empat tipe dasar: int (bilangan bulat), float (desimal), str (teks), bool (True/False).
  • Casting: ubah tipe dengan int(), float(), atau str() — sering dipakai saat kolom angka terbaca sebagai teks.
  • Operator: aritmatika (+ - * / // % **) dan logika (and, or, not).
  • f-string: cara rapi menyisipkan nilai ke dalam teks untuk laporan.
harga = 150000
diskon = 0.1
print(f"Bayar: Rp{harga * (1 - diskon):,.0f}")
# Bayar: Rp135,000

03. Struktur Data: List, Dict, Tuple, Set

Indexing, slicing, list comprehension, nested structures

Struktur data menentukan cara Anda menyimpan sekumpulan nilai. Analoginya: list seperti daftar belanja, dict seperti buku kontak, set seperti daftar ISBN unik.

view_list Poin Kunci

  • List [a, b] — urut, bisa diubah, boleh duplikat. Struktur paling sering dipakai.
  • Tuple (a, b) — tidak bisa diubah; cocok untuk data tetap seperti koordinat.
  • Dict {k: v} — pasangan kunci-nilai, akses cepat berdasarkan kunci.
  • Set {a, b} — hanya nilai unik; berguna untuk menghitung anggota berbeda.
  • Indexing & slicing: data[0], data[1:3], dan list comprehension untuk transformasi singkat.
harga = [12000, 45000, 8000, 45000]
mahal = [h for h in harga if h > 10000]
print(mahal)        # [12000, 45000, 45000]
print(len(set(harga)))  # 3 nilai unik

04. Control Flow & Fungsi

if/elif/else, for, while, def, lambda, *args/**kwargs, scope

Analisis data penuh percabangan dan pengulangan. Fungsi membuat logika itu bisa dipakai ulang, bukan disalin-tempel berulang kali.

account_tree Poin Kunci

  • Percabangan: if / elif / else untuk memilih langkah berdasarkan kondisi.
  • Loop: for untuk mengulang sejumlah data, while selama kondisi terpenuhi, dengan break/continue untuk kontrol.
  • Fungsi: def + return untuk membungkus logika; lambda untuk fungsi singkat sekali pakai.
  • Scope: pahami beda variabel lokal dan global agar tidak salah mengubah data.
def margin(harga, biaya):
    return (harga - biaya) / harga * 100

print(f"Margin: {margin(150000, 90000):.1f}%")
# Margin: 40.0%

05. NumPy: Komputasi Numerik

ndarray, broadcasting, vectorization, operasi statistik, reshape, random

NumPy adalah mesin di balik Pandas. Ia menyimpan angka dalam array dan menghitungnya jauh lebih cepat daripada loop Python biasa.

grid_4x4 Poin Kunci

  • ndarray: wadah angka cepat, satu dimensi (vektor) atau banyak dimensi (matriks).
  • Vectorization: operasi langsung ke seluruh array tanpa loop manual.
  • Broadcasting: menghitung array berbeda bentuk dengan aturan pelebaran otomatis.
  • Statistik: .mean(), .sum(), .std(), .min(), .max().
import numpy as np
harga = np.array([12000, 45000, 8000])
print(harga * 1.11)   # tambah PPN 11% ke semua elemen
print(harga.mean())   # 21666.67

06. Pandas: Manipulasi Data

Series, DataFrame, read_csv/excel, filtering, loc/iloc, sorting, missing values

Pandas adalah alat kerja utama Data Analyst. Di sini Anda belajar membaca tabel dan mengambil baris/kolom yang relevan — keterampilan yang setara dengan SELECT ... WHERE di SQL.

table_chart Poin Kunci

  • Membaca data: pd.read_csv() dan pd.read_excel().
  • Inspeksi cepat: .head(), .info(), .describe(), .shape.
  • Seleksi: loc berdasarkan label, iloc berdasarkan posisi indeks.
  • Filter & urut: filter boolean df[df["nilai"] > 500000] dan .sort_values().
import pandas as pd
df = pd.read_csv("penjualan.csv")
df[df["status"] == "Completed"].sort_values(
    "total", ascending=False
).head()

07. Pandas Lanjutan: GroupBy, Merge, Pivot

groupby(), agg(), merge(), concat(), pivot_table(), melt(), apply()

Di sinilah data mentah berubah menjadi jawaban bisnis: merangkum per kelompok, menggabungkan tabel, dan mengubah bentuk data agar siap divisualisasikan.

merge Poin Kunci

  • groupby + agg: rangkum beberapa metrik sekaligus per kelompok.
  • merge(): gabungkan tabel seperti JOIN di SQL — tentukan how="left" agar baris kiri tetap utuh.
  • concat(): susun tabel secara vertikal atau horizontal.
  • pivot_table() & melt(): ubah bentuk lebar ke panjang dan sebaliknya agar cocok untuk chart.
ringkasan = df.groupby("kategori").agg(
    total_nilai=("nilai", "sum"),
    jumlah_order=("order_id", "nunique"),
).reset_index()

08. Data Cleaning & Preprocessing

Nulls, duplikasi, outlier (IQR/Z-score), encoding, normalisasi, regex, pipeline

Data kotor adalah hal normal. Modul ini melatih kebiasaan seorang analyst: mendiagnosis masalah dulu, baru memutuskan strategi — bukan asal menghapus baris.

cleaning_services Poin Kunci

  • Diagnosis: df.isnull().sum(), df.duplicated().sum(), cek df.dtypes.
  • Penanganan: dropna(), fillna() dengan median/modus, drop_duplicates().
  • Outlier: deteksi lewat aturan IQR atau Z-score sebelum diputuskan dibuang.
  • Standarisasi: rapikan teks dengan regex, normalisasi skala, dan encoding kategorikal.
# Isi nilai kosong dengan median, hapus duplikat
df["umur"] = df["umur"].fillna(df["umur"].median())
df = df.drop_duplicates(subset=["customer_id"])

09. Visualisasi Data: Matplotlib & Seaborn

figure, axes, subplot, heatmap, pairplot, boxplot, customization & styling

Grafik yang baik bukan hiasan — ia menjawab satu pertanyaan dengan jelas. Matplotlib memberi kontrol penuh, Seaborn mempercepat pembuatan chart statistik.

insert_chart Poin Kunci

  • Struktur Matplotlib: figure (kanvas) → axes (area plot) → subplot untuk panel jamak.
  • Jenis chart: bar (perbandingan kategori), line (tren waktu), scatter (hubungan variabel), histogram (distribusi).
  • Seaborn: heatmap korelasi, pairplot antar-variabel, boxplot sebaran per kelompok.
  • Prinsip: satu grafik = satu pesan; beri judul, label sumbu, dan satuan.
import seaborn as sns
import matplotlib.pyplot as plt

sns.barplot(data=df, x="kategori", y="nilai")
plt.title("Penjualan per Kategori")
plt.show()

10. Exploratory Data Analysis (EDA)

Alur EDA sistematis, univariate/bivariate/multivariate, profiling, storytelling

EDA adalah fase investigasi: mengajukan pertanyaan ke data sebelum menarik kesimpulan. Tujuannya menemukan pola, anomali, dan hubungan yang layak ditindaklanjuti.

query_stats Poin Kunci

  • Urutan sistematis: bentuk & tipe data → nilai kosong → distribusi → korelasi → anomali.
  • Tiga tingkat: univariate (satu kolom), bivariate (dua kolom), multivariate (banyak kolom).
  • Alat andalan: describe(), histogram, corr(), dan scatter plot.
  • Output: bukan sekadar chart, tetapi kalimat insight yang bisa ditindaklanjuti.
df.describe()
df.corr(numeric_only=True)
df.groupby("segment")["revenue"].mean()

11. Statistik Deskriptif & Inferensial

Mean, median, std, distribusi, korelasi, t-test, chi-square, confidence interval

Statistik membuat Anda bisa berkata "perbedaan ini nyata", bukan sekadar "kelihatannya berbeda". Inilah dasar pengambilan keputusan berbasis bukti dan A/B testing.

functions Poin Kunci

  • Deskriptif: mean, median, standar deviasi, dan kuartil untuk merangkum data.
  • Distribusi: pahami bentuk sebaran sebelum memilih uji yang tepat.
  • Korelasi: mengukur kekuatan hubungan, bukan sebab-akibat.
  • Inferensial: t-test, chi-square, p-value, dan confidence interval untuk menguji hipotesis.
from scipy import stats
t, p = stats.ttest_ind(grup_kontrol, grup_perlakuan)
print(f"p-value: {p:.4f}")  # p < 0.05 → berbeda signifikan

End-to-end project, Jupyter best practices, Git untuk DA, interview prep

Tugas Praktik

Bangun Skrip Analisis Pertama

Tiga tugas ini menghasilkan portofolio pertama Anda: skrip yang membaca, merangkum, dan memvisualisasikan data.

0 dari 3 tugas selesai
  1. 1

    Siapkan Lingkungan

    Pastikan Python dan library utama berjalan sebelum mulai menulis analisis.

    • Pasang Python, lalu jalankan pip install pandas numpy matplotlib.
    • Buka Jupyter Notebook atau Google Colab.
    • Jalankan import pandas as pd; print(pd.__version__).
    flag Hasil yang dikumpulkan: Cetakan versi library sebagai bukti lingkungan siap.
  2. 2

    Skrip Ringkasan Penjualan

    Buat file analisis.py yang membaca dataset dan merangkumnya.

    • Baca CSV (boleh contoh CSV dari halaman Studi Kasus E-Commerce).
    • Tampilkan 5 baris pertama, jumlah baris, dan tipe data tiap kolom.
    • Hitung ringkasan penjualan per kategori memakai groupby.
    flag Hasil yang dikumpulkan: File analisis.py + keluaran konsol: 5 baris teratas, jumlah baris, dan tabel ringkasan per kategori.
  3. 3

    Satu Grafik, Satu Insight

    Visualisasi bukan hiasan — setiap grafik harus menjawab pertanyaan.

    • Buat grafik batang penjualan per kategori dan grafik garis tren.
    • Simpan grafik sebagai file PNG.
    • Tulis satu kalimat insight yang bisa ditindaklanjuti dari grafik tersebut.
    flag Hasil yang dikumpulkan: File PNG + satu kalimat insight.
