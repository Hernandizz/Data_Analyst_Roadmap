Sebelum menyentuh kode, kenali tiga hal yang akan dipakai terus di sepanjang sesi ini:

  • Metode utama. .isna() untuk memetakan nilai kosong, .fillna() untuk mengisinya, dan .duplicated() untuk menandai baris ganda.
  • Tipe masalah. Pahami apakah data hilang secara acak (MCAR) atau bergantung variabel lain (MAR) — jenisnya menentukan boleh tidaknya imputasi dilakukan.
  • Efek samping. Imputasi yang salah memicu distortion distribusi dan data leakage yang membuat hasil analisis menyesatkan.

Sesi ini memakai dataset sampel 13.000 baris bergaya data pelanggan telekomunikasi dengan kolom identitas, demografi, dan nilai transaksi. Semua kode bisa Anda jalankan ulang di notebook sendiri.

02

Metode Penanganan: Drop vs Imputasi

Pembersihan bukan hanya soal membuat tabel tampak penuh tanpa NaN. Setiap keputusan mengubah varians distribusi data Anda:

Drop Missing Rows / Columns Metode 1

Tepat jika identitas baris bergantung mutlak pada kolom tersebut (misal ID pelanggan atau email autentikasi), atau jika rasio missing > 65% sehingga kolom tak lagi bermakna secara prediktif. 

# Hapus baris hanya jika email NaN
df = df.dropna(subset=['email'])
warning Berkurangnya ukuran sampel bersifat permanen — tidak bisa dikembalikan.

Imputasi Mean / Median / Modus Metode 2

Gunakan Median ketika data numerik memiliki pencilan (miring/skewed), seperti usia atau gaji. Gunakan Modus untuk variabel kategorikal diskrit, atau isi label "Unknown" bila tidak ada dominasi jelas. 

# Mengisi NaN usia dengan nilai median
median_val = df['age'].median()
df['age'] = df['age'].fillna(median_val)
check_circle Menjaga jumlah observasi tanpa mengorbankan sample size.

df_clean['age'] = df_clean['age'].fillna(median_age).astype(int)

# 3. Format total spending dan hilangkan duplikasi
df_clean = df_clean.drop_duplicates(subset=['customer_id'])

Studi Kasus: Bahaya Laten Data Leakage

Hati-hati terhadap Data Leakage saat melakukan pengisian data agregat sebelum pemisahan data training/testing. Menghitung nilai mean/median di seluruh dataset sebelum pemisahan data akan membocorkan informasi populasi masa depan ke model evaluasi. 

# Pendekatan yang Benar (Best Practice):
X_train, X_test = train_test_split(df, test_size=0.2)
median_age = X_train['age'].median()  # Hitung hanya dari train set
X_train['age'].fillna(median_age, inplace=True)
X_test['age'].fillna(median_age, inplace=True)  # Terapkan nilai median train ke test

Tugas Praktik

Bersihkan Satu Dataset Sampai Tuntas

Kerjakan tiga tugas berikut pada satu dataset yang sama sehingga hasilnya berupa laporan pembersihan utuh.

0 dari 3 tugas selesai
  1. 1

    Diagnosa Dataset

    Petakan masalah data sebelum menyentuh satu nilai pun.

    • Unduh contoh CSV dari halaman Studi Kasus E-Commerce.
    • Jalankan df.shape, df.dtypes, df.isna().sum(), dan df.duplicated().sum().
    • Catat kolom mana saja yang bermasalah dan seberapa parah.
    flag Hasil yang dikumpulkan: Tabel diagnosa: nama kolom, jumlah nilai kosong, tipe data, dan jumlah duplikat.
  2. 2

    Putuskan Drop atau Imputasi

    Setiap keputusan harus punya alasan, bukan asal pilih metode.

    • Tentukan strategi per kolom: identitas → drop, numerik → median/mean, kategorikal → modus atau label "Unknown".
    • Jalankan drop_duplicates() dan fillna() sesuai keputusan tadi.
    • Catat alasan singkat untuk setiap keputusan.
    flag Hasil yang dikumpulkan: Kode 5–10 baris + jumlah baris sebelum dan sesudah pembersihan.
  3. 3

    Verifikasi & Catatan Keputusan

    Buktikan dataset sudah bersih, lalu dokumentasikan.

    • Jalankan ulang fungsi diagnosa.
    • Pastikan kolom wajib bersih (0 nilai kosong) dan duplikat hilang.
    • Tulis 3 kalimat: apa yang diubah, mengapa, dan dampaknya ke analisis.
    flag Hasil yang dikumpulkan: Skrip bersih + catatan keputusan 3 kalimat.
