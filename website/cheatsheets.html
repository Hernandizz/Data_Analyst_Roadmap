SQL Aggregation & Windowing

Operasi partisi, ranking, dan rolling analytics di RDBMS / Cloud Warehouse (BigQuery, Snowflake, PostgreSQL).

ANSI SQL / Dialect Agnostic
ROW_NUMBER() / DENSE_RANK() Windowing

Menghasilkan urutan indeks numerik unik per partisi grup data tanpa lompatan nomor.

SELECT user_id, order_date,
  ROW_NUMBER() OVER(
    PARTITION BY user_id 
    ORDER BY order_date DESC
  ) AS rn_order
FROM transactions;
Best for: Deduplikasi urutan O(N log N)
LEAD() & LAG() Offset Time-Series

Mengambil nilai baris setelahnya (LEAD) atau sebelumnya (LAG) untuk evaluasi MoM growth / selisih waktu.

SELECT date, revenue,
  LAG(revenue, 1) OVER(
    ORDER BY date ASC
  ) AS prev_day_rev,
  revenue - LAG(revenue, 1) OVER(
    ORDER BY date ASC
  ) AS delta
FROM daily_sales;
Best for: MoM / DoD Delta No self-join
Conditional Distinct Count Aggregation

Menghitung volume unik hanya jika memenuhi kondisi tertentu tanpa subquery terpisah.

SELECT 
  campaign_id,
  COUNT(DISTINCT CASE 
    WHEN status = 'converted' 
    THEN user_id 
  END) AS paid_converters,
  COUNT(DISTINCT user_id) AS total_reach
FROM ad_logs
GROUP BY 1;
Best for: Funnel Ratio NULL-safe

Pandas Quick Wrangling & Reshaping

Pola transformasi matriks, agregasi multivalue, dan visualisasi format input-output.

Python 3.10+ / Pandas 2.x
df.groupby().agg() Summary

Menerapkan agregasi berbeda ke beberapa kolom secara terarah sekaligus merename output.

summary = df.groupby('segment').agg(
    total_sales=('revenue', 'sum'),
    avg_ticket=('revenue', 'mean'),
    active_users=('user_id', 'nunique')
).reset_index()

pd.pivot_table() Long → Wide

Membuat tabel silang dua dimensi dengan kalkulasi subtotal dan penanganan missing value.

pt = pd.pivot_table(
    df,
    values='gmv',
    index='region',
    columns='quarter',
    aggfunc='sum',
    fill_value=0
)
Format Transformasi:
Rows: [Region] arrow_forward Cols: [Q1, Q2, Q3, Q4]
Best for: Tabulasi Silang Matrix Cross-tab
df.melt() Wide → Long

Menormalkan kolom metrik ganda menjadi baris pasangan variabel-nilai untuk analisis visualisasi.

tidy_df = df.melt(
    id_vars=['user_id', 'country'],
    value_vars=['m1_spend', 'm2_spend'],
    var_name='month_metric',
    value_name='amount'
)

Metrik Bisnis Esensial & Formula

Definisi matematis standar industri untuk pelaporan executive dashboard dan unit economics.

Product & Commercial Analytics
Churn & Retention

Churn Rate (Pelanggan Hilang)

% Rasio
Churn Rate = ( Pelanggan Keluar Periode [t] ) ÷ ( Pelanggan Aktif Awal [t] ) × 100%
check_circle Aplikasi Praktis: Jangan masukkan pendaftar baru tengah periode pada penyebut.
check_circle Target Sehat: B2B SaaS < 1% bulanan; B2C e-commerce di 4-7% bulanan.
Interval: Bulanan / Kuartalan Vital KPI
Valuasi Pelanggan

Customer Lifetime Value (CLV / LTV)

Nominal Monetasi
CLV = ARPU (Rata-rata Pendapatan) × Margin Kotor % ÷ Churn Rate Bulanan
check_circle Benchmark LTV:CAC: Rasio ideal minimal 3:1. Di bawah 1:1 membakar modal.
check_circle Variabel Kritis: Wajib sertakan margin kotor agar tidak melebih-lebihkan proyeksi kas.
Tipe: Unit Economics Executive Metric
Funnel Efisiensi

Conversion Rate (CR) Tahapan

% Konversi
CR Step = ( Entitas Sukses Tahap [N+1] ) ÷ ( Entitas Masuk Tahap [N] ) × 100%
check_circle Contoh: Checkout Success ÷ Payment Visits = Gateway CR.
check_circle Granularitas: Segmentasikan per tipe perangkat (Mobile vs Desktop).
Scope: Product Funnel CRO Indicator
Analisis Kohort

Retention Rate (Day N / Month N)

Cohort Index
Retention (M+n) = ( Pengguna Aktif Bulan [n] dari Kohort K ) ÷ ( Ukuran Awal K ) × 100%
check_circle Product-Market Fit: Kurva retensi yang mendatar menandakan baseline produk kuat.
check_circle Interval Standar: E-commerce memakai M1/M3/M6; Gaming D1/D7/D30.
Model: Triangulasi Kohort PMF Gauge

Statistika Inferensial & Pembersihan Data

Kaidah pengambilan keputusan uji hipotesis A/B testing dan pendeteksian data pencilan.

Rigorous Methods
Interpretasi P-Value A/B Testing

Probabilitas mengamati perbedaan sebesar hasil observasi jika hipotesis nol (H0) bernilai benar.

p < 0.01 Bukti Sangat Kuat Tolak H0
p < 0.05 Signifikan Statistik Standar
p ≥ 0.05 Gagal Tolak H0 (Inkonklusif)
Catatan: Tentukan sample size di awal α = 0.05
Standardisasi Z-Score Normal Dist

Berapa banyak simpangan baku suatu titik data berada dari nilai rata-rata (mean).

Z = ( X - μ ) ÷ σ
X: observasi, μ: mean, σ: standar deviasi
|Z| > 2.0 : 5% populasi terluar
|Z| > 3.0 : Outlier ekstrem (<0.3% prob)
Syarat: Distribusi normal Gaussian Parametrik
Aturan Outlier IQR Tukey's Rule

Metode pembersihan pencilan yang tangguh (robust) terhadap skewed data distribusi miring.

IQR = Q3 (P75) - Q1 (P25)
Batas Bawah = Q1 - (1.5 × IQR)
Batas Atas = Q3 + (1.5 × IQR)
Best for: Income & Basket Value Non-Parametrik

Fungsi Spreadsheet Modern (Excel & Google Sheets)

Alternatif berperforma tinggi untuk menggantikan fungsi lawas VLOOKUP yang rapuh.

Modern Formula Syntax
XLOOKUP() Modern Lookup

Pencarian data dua arah tahan-geser kolom dan mendukung default fallback value.

Rekomendasi 
=XLOOKUP(A2, Users!A:A, Users!D:D, "Tidak Ditemukan", 0)
• Argumen 4: Nilai fallback jika tidak ditemukan (mengeliminasi wrapper =IFERROR)
• Keuntungan: Tidak rusak saat menyisipkan atau memindahkan kolom di sheet referensi.
Kompatibilitas: Excel 365, 2021+, Sheets Anti-Breakage
FILTER() + UNIQUE() Array Formulas

Menghasilkan dynamic spill-down array berdasarkan kriteria kondisional ganda.

Dynamic Array 
=SORT(UNIQUE(FILTER(Sales!B2:B, Sales!C2:C = "Won")), 1, TRUE)
• Spill behavior: Formula hanya ditulis pada sel teratas dan mengisi otomatis sel ke bawah.
• Kombinasi: Gabungkan dengan SUM() untuk kalkulasi agregat tanpa helper column.
Kompatibilitas: Modern Spreadsheets Zero-Helper
