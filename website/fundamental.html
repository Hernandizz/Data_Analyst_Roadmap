Apa itu Data Analyst?

Peran, Tanggung Jawab & Skill Set

Seorang Data Analyst adalah profesional yang mengumpulkan, membersihkan, menganalisis, dan memvisualisasikan data untuk membantu organisasi membuat keputusan bisnis yang lebih baik berdasarkan bukti (evidence-based decision making).

target Tanggung Jawab Utama

  • Mengumpulkan data dari berbagai sumber (database, API, spreadsheet)
  • Membersihkan dan memvalidasi kualitas data
  • Melakukan analisis eksploratif (EDA)
  • Membuat visualisasi dan dashboard
  • Menyampaikan insight melalui data storytelling

build Skill Set yang Dibutuhkan

SQL Python / R Excel Power BI / Tableau Statistika Data Storytelling Critical Thinking

Descriptive Analytics

"Apa yang telah terjadi?" (What happened?)

Descriptive analytics menggunakan data historis untuk merangkum dan memahami apa yang telah terjadi di masa lalu. Ini adalah fondasi dari semua jenis analitik lainnya.

bar_chart Teknik & Tools

  • Summary Statistics — Mean, Median, Mode, Standard Deviation
  • KPI Dashboards — Revenue, Conversion Rate, Churn Rate
  • Visualisasi — Bar chart, Line chart, Heatmap
  • Reporting — Laporan berkala harian/mingguan/bulanan
Contoh: "Total penjualan bulan lalu adalah Rp 2.5 Miliar, naik 12% dari bulan sebelumnya."
troubleshoot

Diagnostic Analytics

"Mengapa hal tersebut terjadi?" (Why did it happen?)

Diagnostic analytics menyelidiki akar penyebab dari pola atau anomali yang ditemukan dalam descriptive analytics menggunakan teknik drill-down dan root cause analysis.

search Teknik & Tools

  • Root Cause Analysis (RCA) — 5 Whys, Fishbone Diagram
  • Drill-Down Analysis — Menggali data dari level umum ke spesifik
  • Korelasi — Mencari hubungan antar variabel
  • Data Discovery — Eksplorasi pola tersembunyi
Contoh: "Penjualan turun 15% karena kampanye marketing dihentikan di minggu ke-3 dan stok produk A habis."
trending_up

Predictive Analytics

"Apa yang mungkin akan terjadi?" (What is likely to happen?)

Predictive analytics menggunakan model statistik dan machine learning untuk membuat perkiraan tentang kejadian di masa depan berdasarkan pola data historis.

auto_graph Teknik & Tools

  • Time Series Forecasting — ARIMA, Prophet, Exponential Smoothing
  • Regression Analysis — Linear, Logistic Regression
  • Classification — Decision Tree, Random Forest
  • Clustering — K-Means, DBSCAN untuk segmentasi
Contoh: "Berdasarkan tren 12 bulan terakhir, prediksi revenue Q4 akan mencapai Rp 8 Miliar dengan confidence interval 90%."
lightbulb

Prescriptive Analytics

"Tindakan apa yang harus kita ambil?" (What should we do?)

Prescriptive analytics memberikan rekomendasi aksi berdasarkan hasil analisis prediktif, menggunakan optimasi dan simulasi untuk membantu pengambilan keputusan.

lightbulb Teknik & Tools

  • Optimization — Linear Programming, Integer Programming
  • Simulation — Monte Carlo, What-If Scenarios
  • A/B Testing — Eksperimen terkontrol untuk validasi
  • Decision Framework — Cost-Benefit Analysis, Decision Tree
Contoh: "Untuk mencapai target Q4, alokasikan 40% budget marketing ke channel digital dan naikkan harga produk B sebesar 5%."

Key Concepts of Data

Konsep-konsep inti dalam siklus hidup pengolahan data

cloud_download

Data Collection

Proses pengumpulan informasi dari berbagai sumber

Data collection adalah proses mengumpulkan informasi dari berbagai sumber internal dan eksternal yang relevan untuk digunakan dalam analisis.

cloud_download Jenis Sumber Data

  • Internal — Sistem ERP, database penjualan, laporan keuangan
  • Eksternal — Survei pelanggan, media sosial, data pasar, API pihak ketiga

list_alt Langkah Utama

  1. Menentukan tujuan pengumpulan data
  2. Memilih sumber data yang tepat
  3. Mengumpulkan data secara terstruktur
  4. Menyimpan data dalam format yang mudah diproses
cleaning_services

Data Cleanup

Membersihkan data agar siap dianalisis

Data cleanup atau data cleaning adalah proses memperbaiki atau menghapus data yang tidak akurat, tidak lengkap, duplikat, atau tidak relevan dari dataset.

cleaning_services Proses Pembersihan

  • Menangani nilai kosong (missing values / NaN)
  • Menghapus data duplikat
  • Memperbaiki format data yang tidak konsisten
  • Mendeteksi dan menangani outlier
explore

Data Exploration

Eksplorasi awal untuk memahami karakteristik data

Data exploration atau Exploratory Data Analysis (EDA) adalah proses investigasi awal untuk menemukan pola, anomali, dan hubungan antar variabel dalam dataset.

explore Teknik Eksplorasi

  • Melihat distribusi variabel (histogram, box plot)
  • Analisis korelasi antar variabel
  • Summary statistics (mean, median, std, quartile)
  • Identifikasi pola dan tren awal
insert_chart

Data Visualisation

Menyajikan data dalam bentuk visual yang mudah dipahami

Data visualisation adalah proses menerjemahkan data menjadi representasi grafis seperti chart, diagram, dan dashboard untuk memudahkan pemahaman insight.

insert_chart Jenis Visualisasi Utama

  • Bar/Column Chart — Perbandingan kategori
  • Line Chart — Tren data sepanjang waktu
  • Scatter Plot — Hubungan antar variabel
  • Heatmap — Korelasi dan distribusi 2D
functions

Statistical Analysis

Menerapkan metode statistik untuk mengambil kesimpulan

Statistical analysis menggunakan metode matematika dan probabilitas untuk mengumpulkan, menganalisis, dan menarik kesimpulan dari data.

straighten Konsep Kunci

  • Statistik Deskriptif — Central tendency, dispersion
  • Statistik Inferensial — Hypothesis testing, confidence interval
  • Regresi — Linear, logistic regression
  • Probabilitas — Distribusi normal, Bayes theorem
psychology

Machine Learning

Pengenalan algoritma pembelajaran mesin untuk analisis data

Machine learning adalah cabang AI yang memungkinkan komputer belajar dari data tanpa diprogram secara eksplisit, untuk membuat prediksi atau keputusan.

smart_toy Jenis Machine Learning

  • Supervised Learning — Classification, Regression
  • Unsupervised Learning — Clustering, Dimensionality Reduction
  • Algoritma Populer — Decision Tree, Random Forest, K-Means, XGBoost
