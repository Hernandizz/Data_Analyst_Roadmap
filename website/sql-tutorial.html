SQL: Memilih dan Memfilter Baris Data (SELECT & WHERE)

Dalam pekerjaan harian data analyst, Anda jarang membutuhkan keseluruhan tabel database. Klausa SELECT mendefinisikan kolom metrik yang ingin Anda evaluasi, sedangkan klausa WHERE menyaring baris berdasarkan kriteria bisnis spesifik dari jutaan rekaman mentah dalam hitungan detik.

Menyaring data dengan SELECT & WHERE

Dua klausa yang paling sering dipakai di pekerjaan harian. Setelah membaca, Anda akan langsung berlatih di SQL editor sungguhan — bukan sekadar membaca sintaks.

Sebelum menulis kueri, pahami dulu mengapa dua klausa ini menjadi bekal wajib seorang analyst. SELECT menentukan kolom metrik yang ingin Anda tarik, sedangkan WHERE memutuskan baris mana yang lolos. Kombinasi keduanya adalah cara menerjemahkan pertanyaan bisnis menjadi perintah yang bisa dijalankan mesin.

Ada tiga alasan klausa ini paling sering muncul di pekerjaan harian Data Analyst:

  • Filter presisi. Hanya baris dengan kondisi bernilai TRUE yang dikembalikan mesin SQL; sisanya diabaikan.
  • Efisiensi biaya. Memangkas kolom dan baris sejak awal menurunkan beban komputasi — sekaligus tagihan — di cloud warehouse seperti BigQuery atau Snowflake.
  • Output siap analisis. Hasil yang sudah terarah lebih mudah langsung dikonversi menjadi DataFrame Pandas atau grafik.

Contoh paling sederhana: daripada menarik seluruh tabel orders berisi ratusan ribu baris, Anda cukup meminta transaksi berstatus Completed di atas nilai tertentu. Di bawah ini kita bahas sintaksnya, operatornya, lalu berlatih langsung.

Sintaks Dasar Standar ANSI SQL

Struktur penulisan query filter mengikuti urutan logis: pilih kolom yang dibutuhkan, sebutkan tabel sumber, lalu tentukan kondisi filter pada baris data.

syntax_pattern.sql 
SELECT customer_name, city, total_spent
FROM orders
WHERE status = 'Completed' AND total_spent >= 500000

Tabel Operator Logika & Perbandingan

Gunakan operator komparasi berikut di dalam klausa WHERE untuk mengisolasi baris data yang relevan:

OPERATOR CONTOH PENGGUNAAN DESKRIPSI & LOGIKA BISNIS
= country = 'Indonesia' Pencocokan persis (exact match). Mengambil nilai yang sama identik.
!= atau <> status != 'Cancelled' Tidak sama dengan. Menolak baris transaksi yang dibatalkan pengguna.
>, <, >=, <= age >= 21 AND score < 80 Perbandingan numerik atau rentang tanggal kronologis.
BETWEEN price BETWEEN 100 AND 500 Termasuk nilai batas atas dan batas bawah (inklusif ranges).
IN (...) city IN ('Jakarta', 'Bandung') Mengevaluasi keanggotaan terhadap daftar nilai kategori jamak.
LIKE email LIKE '%@gmail.com' Pencocokan pola string (wildcard). Simbol % mewakili 0 atau banyak karakter.
warning
Catatan Praktik Lapangan (Analyst Tip: Sargability & Biaya Query) Best Practice

Hindari membungkus kolom dalam fungsi matematis atau string di klausal WHERE jika tidak mendesak. Contoh: Jangan gunakan WHERE YEAR(order_date) = 2024 karena indeks database menjadi tidak aktif ("non-sargable query"), sehingga database harus memindai ("full-table scan") seluruh miliaran baris.

Alternatif Lebih Cepat: Gunakan WHERE order_date >= '2024-01-01' AND order_date < '2025-01-01'. Pada platform BigQuery atau Snowflake, kebijakan ini dapat menghemat anggaran komputasi hingga 80%.

Tugas Praktik

Latihan Kueri di Editor Sungguhan

Tulis kueri di editor, bukan di kepala. Kalau hasilnya error, itu bagian dari belajar — perbaiki dan catat penyebabnya.

0 dari 3 tugas selesai
  1. 1

    Siapkan Tempat Berlatih

    Pilih satu editor SQL gratis dan pastikan bisa menjalankan kueri.

    • Buka BigQuery Sandbox (gratis, tanpa kartu kredit) atau SQLite/DB Fiddle.
    • Muat satu tabel contoh: dataset publik, file CSV, atau tabel bawaan editor.
    • Jalankan SELECT * FROM nama_tabel LIMIT 10; sampai baris muncul.
    flag Hasil yang dikumpulkan: Satu kueri pertama yang berjalan + nama tabel yang Anda pakai.
  2. 2

    Lima Kueri Filter Bisnis

    Untuk tiap kueri, pilih kolom tertentu (hindari SELECT *) dan tambahkan WHERE.

    • Filter satu kategori: WHERE kolom = 'nilai'.
    • Gabungkan dua kondisi memakai AND.
    • Pakai OR bersama tanda kurung agar logika benar.
    • Gunakan BETWEEN (atau >= dan <=) untuk rentang tanggal atau angka.
    • Cari pola teks dengan LIKE '%kata%'.
    flag Hasil yang dikumpulkan: 5 kueri tersimpan, masing-masing disertai jumlah baris hasil.
  3. 3

    Dari Pertanyaan Bisnis ke SQL

    Latih penerjemahan bahasa manusia menjadi kueri.

    • Tulis 3 pertanyaan bisnis nyata (contoh: "pesanan dengan nilai di atas 500.000").
    • Terjemahkan tiap pertanyaan menjadi SELECT ... WHERE.
    • Kerjakan Mini Latihan Interaktif di halaman ini tanpa melihat jawaban dulu.
    flag Hasil yang dikumpulkan: 3 kueri + skor mini latihan (target 100%).
