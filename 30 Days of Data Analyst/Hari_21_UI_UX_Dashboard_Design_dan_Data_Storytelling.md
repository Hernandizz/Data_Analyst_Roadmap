# 📘 Hari 21: UI/UX Dashboard Design & Data Storytelling

Dashboard yang hebat tidak hanya akurat secara angka, tetapi juga memandu mata pembaca untuk menemukan wawasan bisnis (*actionable insights*) dalam hitungan 5 detik pertama.

---

## 🎯 Target Pembelajaran
1. Menerapkan prinsip desain UI/UX: Hierarki Visual, *Gestalt Principles*, dan Aturan Palet Warna 60-30-10.
2. Memilih jenis visualisasi yang tepat sesuai tujuan komunikasi data.
3. Mengembangkan interaktivitas tingkat lanjut: *Custom Tooltip Pages*, *Drill-Through*, *Bookmarks & Selection Pane*.
4. Mengurangi *Chart Clutter* (kebisingan visual yang tidak perlu).

---

## 🧠 Panduan Pemilihan Visualisasi Data

```
┌───────────────────────────┬───────────────────────────────────────────┐
│       TUJUAN ANALISIS     │            JENIS CHART TERBAIK            │
├───────────────────────────┼───────────────────────────────────────────┤
│ Perbandingan Kategori     │ Clustered Bar / Column Chart (Horizontal) │
│ Tren Terhadap Waktu       │ Line Chart / Area Chart                   │
│ Hubungan / Korelasi       │ Scatter Plot                              │
│ Komposisi Bagian ke Total │ Treemap / Donut Chart (Max 3-5 Kategori)  │
│ Nilai KPI Utama           │ Card (New Card Visual) / KPI Visual       │
│ Distribusi & Sebaran      │ Histogram / Box Plot                      │
└───────────────────────────┴───────────────────────────────────────────┘
```

---

### Prinsip Desain Eksekutif (Golden Rules):
1. **Aturan F-Pattern / Z-Pattern:** Taruh KPI terpenting di pojok kiri atas, karena mata manusia membaca dari kiri atas ke kanan bawah.
2. **Aturan Warna 60-30-10:**
   - **60% Warna Dasar / Background:** Netral (Putih, Abu-abu sangat muda `#F8F9FA`, atau Gelap `#1E1E2E`).
   - **30% Warna Struktur:** Navy Blue / Slate Gray untuk kartu dan bar grafik.
   - **10% Warna Aksen (Pemberi Aksen):** Cyan / Oranye terang hanya untuk menyorot alert atau target tercapai/gagal.
3. **Format Angka Kompak:** Jangan tulis `Rp 14.521.890.123` di kartu KPI; tulis `Rp 14.52 M` agar mudah dibaca.
