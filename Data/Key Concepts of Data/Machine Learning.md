# Machine Learning

## Definisi
Machine learning adalah cabang kecerdasan buatan yang memungkinkan komputer belajar dari data dan membuat prediksi atau keputusan tanpa diprogram secara eksplisit untuk setiap tugas.

## Mengapa Penting?
- Mengotomatisasi proses analisis yang kompleks
- Memungkinkan prediksi berdasarkan pola data
- Membantu menemukan insight yang sulit dilihat secara manual

## Jenis Umum
- **Supervised learning**: model dilatih dengan data berlabel untuk memprediksi output.
- **Unsupervised learning**: model mencari pola tanpa label, seperti segmentasi dan clustering.
- **Reinforcement learning**: model belajar dari umpan balik untuk mengambil tindakan terbaik.

## Contoh
- Memprediksi perilaku pelanggan berdasarkan riwayat pembelian
- Mengelompokkan produk ke dalam segmen pelanggan
- Mengoptimalkan penjadwalan atau rute logistik dengan algoritma cerdas
