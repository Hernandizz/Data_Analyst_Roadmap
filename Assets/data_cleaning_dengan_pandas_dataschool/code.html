Data Cleaning: Menangani Nilai Kosong (NaN) dan Duplikasi

80% waktu seorang Data Analyst dihabiskan untuk merapikan dataset mentah sebelum tahap visualisasi atau modeling.

Metode Utama .isna() / .fillna()
Tipe Masalah MCAR & MAR Missingness

02

Metode Penanganan: Drop vs Imputasi

Pembersihan bukan hanya soal membuat tabel tampak penuh tanpa NaN. Setiap keputusan mengubah varians distribusi data Anda:

Metode 1: Penghapusan delete_sweep

Drop Missing Rows / Columns

Tepat jika identitas baris bergantung mutlak pada kolom tersebut (misal ID pelanggan, email autentikasi) atau jika rasio missing > 65% sehingga kolom tak bermakna secara prediktif.

# Hapus baris hanya jika email NaN
df = df.dropna(subset=['email'])
warning Menyebabkan berkurangnya ukuran sampel secara permanen.
Metode 2: Imputasi Statistik functions

Imputasi Mean / Median / Modus

Gunakan Median saat data numerik memiliki pencilan (skewed/miring), seperti kolom usia atau gaji. Gunakan Modus untuk variabel kategorikal diskrit.

# Mengisi NaN usia dengan nilai median
median_val = df['age'].median()
df['age'] = df['age'].fillna(median_val)

Studi Kasus: Bahaya Laten Data Leakage

Hati-hati terhadap Data Leakage saat melakukan pengisian data agregat sebelum pemisahan data training/testing. Menghitung nilai mean/median di seluruh dataset sebelum pemisahan data akan membocorkan informasi populasi masa depan ke model evaluasi.

# Pendekatan yang Benar (Best Practice):
X_train, X_test = train_test_split(df, test_size=0.2)
median_age = X_train['age'].median() # Hitung hanya dari train set
X_train['age'].fillna(median_age, inplace=True)
X_test['age'].fillna(median_age, inplace=True) # Terapkan nilai median train ke test

Latihan Mandiri: Tangani Transaksi E-Commerce

Tingkat: Menengah

Diberikan dataframe penjualan dengan kolom transaction_amount yang memiliki 3.5% nilai kosong dan skewness positif yang tinggi (ekstrem kanan). Metode apa yang harus Anda pilih, dan bagaimana sintaks satu barisnya?

Kunci Analisis:

Karena skewness ekstrem kanan (adanya nilai transaksi bernilai ratusan juta), Mean akan tertarik ke atas dan membiaskan estimasi. Selalu gunakan Median.

df['transaction_amount'] = df['transaction_amount'].fillna(df['transaction_amount'].median())
