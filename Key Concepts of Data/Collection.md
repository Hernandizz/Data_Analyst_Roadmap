# Data Collection

## Definisi
Data collection adalah proses mengumpulkan informasi dari berbagai sumber untuk digunakan dalam analisis. Pada tahap ini, data diambil dari sumber internal dan eksternal yang relevan.

## Mengapa Penting?
- Menjadi dasar bagi semua analisis data berikutnya
- Menentukan kualitas dan kecocokan data
- Memastikan data lengkap dan representatif

## Jenis Sumber Data
- Data internal: sistem perusahaan, database penjualan, laporan keuangan
- Data eksternal: survei pelanggan, media sosial, data pasar, API pihak ketiga

## Langkah Utama
1. Menentukan tujuan pengumpulan data
2. Memilih sumber data yang tepat
3. Mengumpulkan data secara terstruktur
4. Menyimpan data dalam format yang mudah diproses

## Contoh
- Mengambil data penjualan dari sistem ERP(Enterprise Resource Planning)
- Mengumpulkan respon survei pelanggan
- Mengakses data cuaca melalui API untuk analisis permintaan
