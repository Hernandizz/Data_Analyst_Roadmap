# Data Visualisation

## Definisi
Data visualisation adalah proses menyajikan data dalam bentuk grafik, diagram, atau dashboard agar informasi lebih mudah dipahami.

## Mengapa Penting?
- Mempercepat pemahaman data
- Menyajikan insight secara visual dan intuitif
- Membantu komunikasi hasil analisis kepada pemangku kepentingan

## Bentuk Visualisasi Umum
- Grafik batang
- Grafik garis
- Diagram lingkaran
- Heatmap
- Dashboard interaktif

## Contoh
- Visualisasi tren penjualan bulanan dengan grafik garis
- Membandingkan pangsa pasar produk menggunakan diagram lingkaran
- Menampilkan performa tim menurut wilayah di dashboard interaktif
