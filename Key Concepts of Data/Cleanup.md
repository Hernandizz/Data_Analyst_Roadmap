# Data Cleanup

## Definisi
Data cleanup adalah proses membersihkan data dari kesalahan, duplikasi, dan nilai yang tidak lengkap. Tujuannya adalah membuat data lebih akurat dan siap untuk analisis.

## Mengapa Penting?
- Meningkatkan keandalan hasil analisis
- Mengurangi kesalahan dan bias
- Memudahkan proses analisis selanjutnya

## Tugas Umum
- Menghapus duplikat data
- Mengisi nilai kosong atau hilang
- Memperbaiki kesalahan penulisan dan format
- Menghapus data yang tidak relevan

## Contoh
- Menggabungkan data pelanggan dari beberapa sumber lalu menghapus entri ganda
- Mengubah format tanggal menjadi standar yang sama
- Menghapus nilai kosong pada kolom penting sebelum analisis
